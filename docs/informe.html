2. Arquitectura Técnica del Sistema

La solución se fundamenta en el patrón arquitectónico Cliente-Servidor Desacoplado, garantizando que el backend funcione de forma independiente de la tecnología del cliente y que el cliente pueda consumir datos a través de contratos HTTP estandarizados.

📱 Capa Frontend: Cliente Flutter (Dart)
• UI / Screens: HomeScreen (Dashboard con pull-to-refresh y búsqueda) y NoteFormScreen (Formulario reactivo).
• Widgets Reutilizables: NoteCard, PriorityBadge, CategoryChipBar, EmptyStateWidget.
• Gestión de Estado: NoteProvider con ChangeNotifier.
• Servicio de Red: NoteApiService con cliente http y resolución dinámica de host.
⬇ ⬆ Peticiones HTTP / JSON con REST API (CORS Habilitado) ⬇ ⬆
⚙ Capa Backend: Servidor REST (Node.js + Express)

• Rutas: note.routes.js (Mapeo de verbos HTTP).
• Controladores: note.controller.js (Validación de entrada y orquestación de respuesta).
• Servicio & Persistencia: note.service.js (Lógica de negocio, filtros y repositorio en memoria con UUID v4).
• Middlewares: error.middleware.js (Captura centralizada de 400, 404 y 500).

2.1. Desacoplamiento y Patrones de Diseño

En el servidor, se implementó el patrón Controller-Service-Repository, separando la lógica de transporte HTTP de las reglas de negocio. En el cliente Flutter, se implementó el patrón Provider / Repository, asegurando que la interfaz de usuario nunca invoque llamadas HTTP directamente, sino a través de métodos asíncronos que mutan el estado y notifican a los observadores mediante notifyListeners().

3. Especificación Detallada de la API REST

La API expone endpoints bajo el prefijo /api. Todas las respuestas devuelven encabezados Content-Type: application/json y un sobre de respuesta uniforme con la estructura: { success: boolean, message: string, data?: object }.

Método Endpoint Parámetros / Cuerpo Código HTTP Descripción
GET /api/health Ninguno 200 OK Monitoreo y health check
GET /api/notes category, priority, isPinned, search 200 OK Listado con filtros y búsqueda
GET /api/notes/:id id en la URL (UUID v4) 200 / 404 Detalle de nota por ID
POST /api/notes { title*, content*, category, priority, isPinned } 201 / 400 Creación de nueva nota
PUT /api/notes/:id Campos a actualizar en body JSON 200 / 400 / 404 Actualización parcial o total
DELETE /api/notes/:id id en la URL 200 / 404 Eliminación física del recurso

8.4. Backend: note.controller.js

backend/src/controllers/note.controller.jsJavaScript
const noteService = require('../services/note.service');

class NoteController {
  getAll(req, res, next) {
    try {
      const { category, priority, isPinned, search } = req.query;
      const notes = noteService.getAll({ category, priority, isPinned, search });

      return res.status(200).json({
        success: true,
        message: 'Notas recuperadas exitosamente',
        data: notes
      });
    } catch (error) {
      return next(error);
    }
  }

  getById(req, res, next) {
    try {
      const { id } = req.params;
      const note = noteService.getById(id);

      if (!note) {
        return res.status(404).json({
          success: false,
          message: `Nota con id '${id}' no encontrada`
        });
      }

      return res.status(200).json({
        success: true,
        message: 'Nota encontrada exitosamente',
        data: note
      });
    } catch (error) {
      return next(error);
    }
  }

  create(req, res, next) {
    try {
      const { title, content, category, priority, isPinned } = req.body;

      if (!title || typeof title !== 'string' || title.trim() === '') {
        return res.status(400).json({
          success: false,
          message: 'El campo "title" es obligatorio y debe ser una cadena no vacía'
        });
      }

      if (!content || typeof content !== 'string' || content.trim() === '') {
        return res.status(400).json({
          success: false,
          message: 'El campo "content" es obligatorio y debe ser una cadena no vacía'
        });
      }

      const newNote = noteService.create({
        title,
        content,
        category,
        priority,
        isPinned
      });

      return res.status(201).json({
        success: true,
        message: 'Nota creada exitosamente',
        data: newNote
      });
    } catch (error) {
      return next(error);
    }
  }

  update(req, res, next) {
    try {
      const { id } = req.params;
      const { title, content, category, priority, isPinned } = req.body;

      if (title !== undefined && (typeof title !== 'string' || title.trim() === '')) {
        return res.status(400).json({
          success: false,
          message: 'El campo "title" no puede estar vacío'
        });
      }

      if (content !== undefined && (typeof content !== 'string' || content.trim() === '')) {
        return res.status(400).json({
          success: false,
          message: 'El campo "content" no puede estar vacío'
        });
      }

      const updated = noteService.update(id, {
        title,
        content,
        category,
        priority,
        isPinned
      });

      if (!updated) {
        return res.status(404).json({
          success: false,
          message: `Nota con id '${id}' no encontrada para actualizar`
        });
      }

      return res.status(200).json({
        success: true,
        message: 'Nota actualizada exitosamente',
        data: updated
      });
    } catch (error) {
      return next(error);
    }
  }

  delete(req, res, next) {
    try {
      const { id } = req.params;
      const deleted = noteService.delete(id);

      if (!deleted) {
        return res.status(404).json({
          success: false,
          message: `Nota con id '${id}' no encontrada para eliminar`
        });
      }

      return res.status(200).json({
        success: true,
        message: 'Nota eliminada exitosamente',
        data: { id }
      });
    } catch (error) {
      return next(error);
    }
  }

  healthCheck(req, res) {
    return res.status(200).json({
      success: true,
      status: 'ok',
      message: 'Servicio en línea',
      data: {
        status: 'UP',
        health: 'ok',
        timestamp: new Date().toISOString()
      }
    });
  }
}

module.exports = new NoteController();

8.5. Backend: note.service.js

backend/src/services/note.service.jsJavaScript
const { v4: uuidv4 } = require('uuid');

const VALID_CATEGORIES = ['Trabajo', 'Estudio', 'Personal', 'Ideas'];
const VALID_PRIORITIES = ['Baja', 'Media', 'Alta'];

class NoteService {
  constructor() {
    this.notes = [
      {
        id: uuidv4(),
        title: 'Planificar arquitectura Flutter',
        content: 'Definir la estructura de carpetas, modelos, proveedores de estado y tema visual en Flutter.',
        category: 'Trabajo',
        priority: 'Alta',
        isPinned: true,
        createdAt: new Date(Date.now() - 3600000 * 24).toISOString(),
        updatedAt: new Date(Date.now() - 3600000 * 24).toISOString()
      },
      {
        id: uuidv4(),
        title: 'Estudiar integración de APIs REST',
        content: 'Repasar buenas prácticas con el paquete http en Dart y manejo seguro de excepciones de red.',
        category: 'Estudio',
        priority: 'Media',
        isPinned: false,
        createdAt: new Date(Date.now() - 3600000 * 12).toISOString(),
        updatedAt: new Date(Date.now() - 3600000 * 12).toISOString()
      },
      {
        id: uuidv4(),
        title: 'Ideas para interfaz Fancy UX',
        content: 'Agregar micro-interacciones, animaciones suaves al filtrar y paleta de colores moderna con modo oscuro.',
        category: 'Ideas',
        priority: 'Baja',
        isPinned: false,
        createdAt: new Date(Date.now() - 3600000 * 4).toISOString(),
        updatedAt: new Date(Date.now() - 3600000 * 4).toISOString()
      }
    ];
  }

  getAll(filters = {}) {
    let result = [...this.notes];

    if (filters.category && filters.category.toLowerCase() !== 'todas' && filters.category.toLowerCase() !== 'all') {
      result = result.filter(n => n.category.toLowerCase() === filters.category.toLowerCase());
    }

    if (filters.priority) {
      result = result.filter(n => n.priority.toLowerCase() === filters.priority.toLowerCase());
    }

    if (filters.isPinned !== undefined) {
      const pinnedBool = String(filters.isPinned).toLowerCase() === 'true';
      result = result.filter(n => n.isPinned === pinnedBool);
    }

    if (filters.search) {
      const term = filters.search.toLowerCase().trim();
      result = result.filter(n =>
        n.title.toLowerCase().includes(term) ||
        n.content.toLowerCase().includes(term)
      );
    }

    // Ordenar: notas fijadas primero, luego por fecha de creación descendente
    return result.sort((a, b) => {
      if (a.isPinned !== b.isPinned) {
        return a.isPinned ? -1 : 1;
      }
      return new Date(b.createdAt) - new Date(a.createdAt);
    });
  }

  getById(id) {
    const note = this.notes.find(n => n.id === id);
    return note || null;
  }

  create(noteData) {
    const now = new Date().toISOString();
    const newNote = {
      id: uuidv4(),
      title: noteData.title.trim(),
      content: noteData.content.trim(),
      category: VALID_CATEGORIES.includes(noteData.category) ? noteData.category : 'Personal',
      priority: VALID_PRIORITIES.includes(noteData.priority) ? noteData.priority : 'Media',
      isPinned: Boolean(noteData.isPinned),
      createdAt: now,
      updatedAt: now
    };

    this.notes.unshift(newNote);
    return newNote;
  }

  update(id, noteData) {
    const index = this.notes.findIndex(n => n.id === id);
    if (index === -1) {
      return null;
    }

    const current = this.notes[index];
    const updatedNote = {
      ...current,
      title: noteData.title !== undefined ? noteData.title.trim() : current.title,
      content: noteData.content !== undefined ? noteData.content.trim() : current.content,
      category: noteData.category && VALID_CATEGORIES.includes(noteData.category)
        ? noteData.category
        : current.category,
      priority: noteData.priority && VALID_PRIORITIES.includes(noteData.priority)
        ? noteData.priority
        : current.priority,
      isPinned: noteData.isPinned !== undefined ? Boolean(noteData.isPinned) : current.isPinned,
      updatedAt: new Date().toISOString()
    };

    this.notes[index] = updatedNote;
    return updatedNote;
  }

  delete(id) {
    const index = this.notes.findIndex(n => n.id === id);
    if (index === -1) {
      return false;
    }
    this.notes.splice(index, 1);
    return true;
  }
}

class NoteApiService {
  final http.Client _client;
  final String _baseUrl;

  NoteApiService({
    http.Client? client,
    String? baseUrl,
  })  : _client = client ?? http.Client(),
        _baseUrl = baseUrl ?? ApiConstants.baseUrl;

  static const Map<String, String> _headers = {
    'Content-Type': 'application/json',
    'Accept': 'application/json',
  };

  Future<List<NoteModel>> getNotes({String? category, String? search}) async {
    try {
      final queryParameters = <String, String>{};
      if (category != null && category.trim().isNotEmpty && category != 'Todas') {
        queryParameters['category'] = category.trim();
      }
      if (search != null && search.trim().isNotEmpty) {
        queryParameters['search'] = search.trim();
      }

      final uri = Uri.parse('$_baseUrl${ApiConstants.notesEndpoint}').replace(
        queryParameters: queryParameters.isNotEmpty ? queryParameters : null,
      );

      final response = await _client
          .get(uri, headers: _headers)
          .timeout(ApiConstants.timeout);

      final Map<String, dynamic> body = _decodeResponse(response);

      if (response.statusCode == 200 && body['data'] is List) {
        final list = body['data'] as List<dynamic>;
        return list
            .map((item) => NoteModel.fromMap(item as Map<String, dynamic>))
            .toList();
      } else {
        throw ApiException(
          body['message']?.toString() ?? 'Error al obtener la lista de notas',
          statusCode: response.statusCode,
        );
      }
    } on SocketException catch (e) {
      throw ApiException('No se pudo conectar con el servidor backend (${e.message})');
    } on TimeoutException {
      throw const ApiException('Tiempo de espera agotado al conectar con el servidor');
    } on ApiException {
      rethrow;
    } catch (e) {
      throw ApiException('Error inesperado al obtener notas: $e');
    }
  }

  Future<NoteModel> getNoteById(String id) async {
    try {
      final uri = Uri.parse('$_baseUrl${ApiConstants.notesEndpoint}/$id');
      final response = await _client
          .get(uri, headers: _headers)
          .timeout(ApiConstants.timeout);

      final Map<String, dynamic> body = _decodeResponse(response);

      if (response.statusCode == 200 && body['data'] is Map<String, dynamic>) {
        return NoteModel.fromMap(body['data'] as Map<String, dynamic>);
      } else {
        throw ApiException(
          body['message']?.toString() ?? 'Nota no encontrada',
          statusCode: response.statusCode,
        );
      }
    } on SocketException catch (e) {
      throw ApiException('Error de conexión al buscar la nota (${e.message})');
    } on TimeoutException {
      throw const ApiException('Tiempo de espera agotado al buscar la nota');
    } on ApiException {
      rethrow;
    } catch (e) {
      throw ApiException('Error inesperado al buscar la nota: $e');
    }
  }

  Future<NoteModel> createNote(NoteModel note) async {
    try {
      final uri = Uri.parse('$_baseUrl${ApiConstants.notesEndpoint}');
      final response = await _client
          .post(
            uri,
            headers: _headers,
            body: jsonEncode({
              'title': note.title,
              'content': note.content,
              'category': note.category,
              'priority': note.priority,
              'isPinned': note.isPinned,
            }),
          )
          .timeout(ApiConstants.timeout);

      final Map<String, dynamic> body = _decodeResponse(response);

      if (response.statusCode == 201 && body['data'] is Map<String, dynamic>) {
        return NoteModel.fromMap(body['data'] as Map<String, dynamic>);
      } else {
        throw ApiException(
          body['message']?.toString() ?? 'Error al crear la nota',
          statusCode: response.statusCode,
        );
      }
    } on SocketException catch (e) {
      throw ApiException('Error de conexión al crear la nota (${e.message})');
    } on TimeoutException {
      throw const ApiException('Tiempo de espera agotado al crear la nota');
    } on ApiException {
      rethrow;
    } catch (e) {
      throw ApiException('Error inesperado al crear la nota: $e');
    }
  }

  Future<NoteModel> updateNote(String id, NoteModel note) async {
    try {
      final uri = Uri.parse('$_baseUrl${ApiConstants.notesEndpoint}/$id');
      final response = await _client
          .put(
            uri,
            headers: _headers,
            body: jsonEncode({
              'title': note.title,
              'content': note.content,
              'category': note.category,
              'priority': note.priority,
              'isPinned': note.isPinned,
            }),
          )
          .timeout(ApiConstants.timeout);

      final Map<String, dynamic> body = _decodeResponse(response);

      if (response.statusCode == 200 && body['data'] is Map<String, dynamic>) {
        return NoteModel.fromMap(body['data'] as Map<String, dynamic>);
      } else {
        throw ApiException(
          body['message']?.toString() ?? 'Error al actualizar la nota',
          statusCode: response.statusCode,
        );
      }
    } on SocketException catch (e) {
      throw ApiException('Error de conexión al actualizar la nota (${e.message})');
    } on TimeoutException {
      throw const ApiException('Tiempo de espera agotado al actualizar la nota');
    } on ApiException {
      rethrow;
    } catch (e) {
      throw ApiException('Error inesperado al actualizar la nota: $e');
    }
  }

  Future<bool> deleteNote(String id) async {
    try {
      final uri = Uri.parse('$_baseUrl${ApiConstants.notesEndpoint}/$id');
      final response = await _client
          .delete(uri, headers: _headers)
          .timeout(ApiConstants.timeout);

      final Map<String, dynamic> body = _decodeResponse(response);

      if (response.statusCode == 200) {
        return body['success'] == true;
      } else {
        throw ApiException(
          body['message']?.toString() ?? 'Error al eliminar la nota',
          statusCode: response.statusCode,
        );
      }
    } on SocketException catch (e) {
      throw ApiException('Error de conexión al eliminar la nota (${e.message})');
    } on TimeoutException {
      throw const ApiException('Tiempo de espera agotado al eliminar la nota');
    } on ApiException {
      rethrow;
    } catch (e) {
      throw ApiException('Error inesperado al eliminar la nota: $e');
    }
  }

  Future<bool> checkHealth() async {
    try {
      final uri = Uri.parse('$_baseUrl${ApiConstants.healthEndpoint}');
      final response = await _client
          .get(uri, headers: _headers)
          .timeout(const Duration(seconds: 5));

      if (response.statusCode == 200) {
        final body = _decodeResponse(response);
        return body['success'] == true || body['data']?['status'] == 'UP';
      }
      return false;
    } catch (_) {
      return false;
    }
  }

  Map<String, dynamic> _decodeResponse(http.Response response) {
    try {
      return jsonDecode(utf8.decode(response.bodyBytes)) as Map<String, dynamic>;
    } catch (_) {
      return {'success': false, 'message': response.body};
    }
  }

  void dispose() {
    _client.close();
  }
}

import 'package:flutter/foundation.dart';

import '../core/errors/api_exception.dart';

class NoteProvider extends ChangeNotifier {
  final NoteApiService _apiService;

  List<NoteModel> _notes = [];
  bool _isLoading = false;
  String? _errorMessage;
  String? _selectedCategory;
  String _searchQuery = '';
  bool _isBackendOnline = false;

  NoteProvider({NoteApiService? apiService})
      : _apiService = apiService ?? NoteApiService();

  List<NoteModel> get notes => List.unmodifiable(_notes);
  bool get isLoading => _isLoading;
  String? get errorMessage => _errorMessage;
  String? get selectedCategory => _selectedCategory;
  String get searchQuery => _searchQuery;
  bool get isBackendOnline => _isBackendOnline;

  List<NoteModel> get pinnedNotes =>
      _notes.where((note) => note.isPinned).toList();

  List<NoteModel> get unpinnedNotes =>
      _notes.where((note) => !note.isPinned).toList();

  Future<void> fetchNotes() async {
    _setLoading(true);
    _errorMessage = null;

    try {
      _notes = await _apiService.getNotes(
        category: _selectedCategory,
        search: _searchQuery,
      );
      _sortNotes();
      _isBackendOnline = true;
    } on ApiException catch (e) {
      _errorMessage = e.message;
      _isBackendOnline = false;
    } catch (e) {
      _errorMessage = 'Error inesperado: $e';
    } finally {
      _setLoading(false);
    }
  }

  Future<bool> createNote(NoteModel note) async {
    _setLoading(true);
    _errorMessage = null;

    try {
      final createdNote = await _apiService.createNote(note);
      // Actualizar lista local manteniendo orden (fijados primero)
      _notes.insert(0, createdNote);
      _sortNotes();
      _isBackendOnline = true;
      notifyListeners();
      return true;
    } on ApiException catch (e) {
      _errorMessage = e.message;
      notifyListeners();
      return false;
    } catch (e) {
      _errorMessage = 'Error al crear la nota: $e';
      notifyListeners();
      return false;
    } finally {
      _setLoading(false);
    }
  }

  Future<bool> updateNote(String id, NoteModel note) async {
    _setLoading(true);
    _errorMessage = null;

    try {
      final updatedNote = await _apiService.updateNote(id, note);
      final index = _notes.indexWhere((n) => n.id == id);
      if (index != -1) {
        _notes[index] = updatedNote;
        _sortNotes();
      }
      _isBackendOnline = true;
      notifyListeners();
      return true;
    } on ApiException catch (e) {
      _errorMessage = e.message;
      notifyListeners();
      return false;
    } catch (e) {
      _errorMessage = 'Error al actualizar la nota: $e';
      notifyListeners();
      return false;
    } finally {
      _setLoading(false);
    }
  }

  Future<bool> deleteNote(String id) async {
    _setLoading(true);
    _errorMessage = null;

    try {
      final success = await _apiService.deleteNote(id);
      if (success) {
        _notes.removeWhere((n) => n.id == id);
      }
      _isBackendOnline = true;
      notifyListeners();
      return success;
    } on ApiException catch (e) {
      _errorMessage = e.message;
      notifyListeners();
      return false;
    } catch (e) {
      _errorMessage = 'Error al eliminar la nota: $e';
      notifyListeners();
      return false;
    } finally {
      _setLoading(false);
    }
  }

  Future<bool> togglePinNote(NoteModel note) async {
    if (note.id == null) return false;
    final updated = note.copyWith(isPinned: !note.isPinned);
    return updateNote(note.id!, updated);
  }

  void setCategory(String? category) {
    if (_selectedCategory == category) return;
    _selectedCategory = (category == null || category == 'Todas') ? null : category;
    fetchNotes();
  }

  void search(String query) {
    if (_searchQuery == query) return;
    _searchQuery = query;
    fetchNotes();
  }

  Future<bool> checkHealth() async {
    final status = await _apiService.checkHealth();
    _isBackendOnline = status;
    notifyListeners();
    return status;
  }

  void clearError() {
    _errorMessage = null;
    notifyListeners();
  }

  void _setLoading(bool value) {
    _isLoading = value;
    notifyListeners();
  }

  void _sortNotes() {
    // Mantiene notas fijadas primero, luego orden por fecha descendente
    _notes.sort((a, b) {
      if (a.isPinned != b.isPinned) {
        return a.isPinned ? -1 : 1;
      }
      return b.createdAt.compareTo(a.createdAt);
    });
  }

  @override
  void dispose() {
    _apiService.dispose();
    super.dispose();
  }
}

    _selectedCategory = widget.note?.category ?? 'Personal';
    _selectedPriority = widget.note?.priority ?? 'Media';
    _isPinned = widget.note?.isPinned ?? false;
  }

  @override
  void dispose() {
    _titleController.dispose();
    _contentController.dispose();
    super.dispose();
  }

  Future<void> _saveNote() async {
    if (!_formKey.currentState!.validate()) return;

    setState(() => _isSaving = true);
    final provider = context.read<NoteProvider>();

    bool success;
    if (_isEditing) {
      final updatedNote = widget.note!.copyWith(
        title: _titleController.text.trim(),
        content: _contentController.text.trim(),
        category: _selectedCategory,
        priority: _selectedPriority,
        isPinned: _isPinned,
      );
      success = await provider.updateNote(widget.note!.id!, updatedNote);
    } else {
      final newNote = NoteModel(
        title: _titleController.text.trim(),
        content: _contentController.text.trim(),
        category: _selectedCategory,
        priority: _selectedPriority,
        isPinned: _isPinned,
        createdAt: DateTime.now(),
        updatedAt: DateTime.now(),
      );
      success = await provider.createNote(newNote);
    }

    if (!mounted) return;
    setState(() => _isSaving = false);

    if (success) {
      ScaffoldMessenger.of(context).showSnackBar(
        SnackBar(
          content: Text(_isEditing ? 'Nota actualizada con éxito' : 'Nota creada con éxito'),
          backgroundColor: AppColors.success,
          behavior: SnackBarBehavior.floating,
        ),
      );
      Navigator.of(context).pop();
    } else {
      ScaffoldMessenger.of(context).showSnackBar(
        SnackBar(
          content: Text(provider.errorMessage ?? 'Error al guardar la nota'),
          backgroundColor: AppColors.error,
          behavior: SnackBarBehavior.floating,
        ),
      );
    }
  }
